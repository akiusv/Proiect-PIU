# Proiect-PIU

## Descriere

Acest proiect urmărește realizarea unei aplicații pentru gestionarea activităților unei companii de transport. Aplicația va permite evidența conducătorilor auto, a vehiculelor disponibile și a intervalelor de lucru pentru fiecare dintre aceștia.

Sistemul va gestiona informații legate de persoanele implicate în activitatea companiei, mașinile aflate în flotă și activitățile desfășurate de acestea. Prin intermediul aplicației vor putea fi consultate și actualizate date despre șoferi, vehicule și traseele realizate.

Printre funcționalitățile aplicației se numără urmărirea numărului de kilometri parcurși de un conducător auto sau de un vehicul, precum și evidența traseelor efectuate. Aceste informații vor ajuta la organizarea și monitorizarea activității companiei.

Aplicația va fi realizată folosind concepte de programare orientată pe obiect și va include o interfață cu meniu și opțiuni pentru gestionarea datelor din sistem. Proiectul va fi dezvoltat progresiv pe parcursul laboratoarelor, prin adăugarea de noi componente și funcționalități.
